# CareerVault & ResumeForge AI

An intelligent, full-stack AI Portfolio Management and Job-Tailored Resume Generation Engine with **Zero-Hallucination Guardrails**, Google Sheets 2-way synchronization, and dual ATS-friendly export (PDF & DOCX).

---

## Key Highlights

- **Centralized Multi-Category Portfolio Database**: Full SQLite/SQLAlchemy schema tracking Profile, Education, Skills (with proficiencies and categories), Projects, Experience, Certifications, Achievements, Publications, Languages, and Extra Activities.
- **Strict Anti-Hallucination Guardrails**: Multi-stage programmatic verification engine that cross-references all AI rankings against database primary keys and validates metric/number invariants. Rewritten bullets cannot fabricate metrics or unverified tools; automatic fallback preserves factual integrity.
- **Smart Resume Import**: Paste unstructured text or upload PDF/DOCX resumes for Gemini structured parsing, complete with an interactive review & diff confirmation screen.
- **Job Description (JD) Analysis & Matching**: Extracts role expectations, required vs preferred skills, and keywords. Computes an objective match score (0-100%) and provides ranked recommendations with human-readable justifications.
- **2-Way Google Sheets Synchronization**: Multi-tab export (one worksheet per category) and sync-back engine with automatic service account integration and local mock sandbox mode.
- **ATS Resume Generator**: Live preview with dual professional templates (Modern Clean & Classic Ivy), supporting one-click PDF and DOCX downloads.
- **Resume History**: Saves every tailored resume session for one-click re-opening and regeneration.

---

## Tech Stack

- **Backend**: Python 3.14+, FastAPI, SQLAlchemy ORM, Pydantic v2, Uvicorn
- **AI Engine**: Google Gemini API (`google-genai` SDK) with structured JSON schemas
- **Google Sheets**: `gspread` & Google Cloud Service Account
- **Export Engines**: ReportLab (PDF) & `python-docx` (DOCX)
- **Frontend**: React (Vite) + Tailwind CSS + Lucide Icons
- **Testing**: Pytest automated test suite (CRUD, Guardrails, Matching, Sheets, and Import)

## Getting Started

### 1. Prerequisites
- Python 3.10+ (Tested on Python 3.14)
- Node.js 18+ and npm

### 2. Backend Setup
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
# Edit .env with your GEMINI_API_KEY if available

# Seed the database with realistic dummy portfolio data (Alex Rivera)
python scripts/seed_data.py

# Run backend server
uvicorn app.main:app --reload --port 8000
```
Backend API interactive documentation will be available at `http://localhost:8000/docs`.

### 3. Run Automated Tests
```bash
pytest backend/tests/ -v
```

## Anti-Hallucination Guardrail Architecture

The system enforces rigorous verification safeguards:
1. **ID Whitelist Verification**: All project, experience, and skill IDs generated by AI are verified against SQLite primary keys. Any unrecognized ID is immediately discarded.
2. **Numeric & Metric Invariant Enforcement**: Regex token analyzers check all metrics, percentages (e.g., `45%`), volume numbers (e.g., `25M+`), and dollar amounts against verified source records.
3. **Automatic Fallback Safety**: If an AI-suggested rephrase fails invariant verification twice, the system automatically falls back to the original verified portfolio text.
